Banger is a to-do widget for your Mac desktop. Every task you finish gets a party. This one is live, so check something off.

Get Banger Free and open source

Finishing should feel like something.

Banger was built with ADHD in mind, where out of sight is out of mind and a reward only works if it is immediate. The list stays on your desktop. The reward lands the moment you click.

Three sizes of party.

A streak you can see.

Clear every task in a day and your streak goes up by one. The flame grows the longer it runs.

One missed day a week is free. The shield means it is ready.

Let your AI assistant fill the list.

Any assistant that can run a Terminal command can add your tasks each morning, or read them back to you. No account, no login, no setup.

Or add one yourself, from any app.

Build it on your Mac.

There is no ready-made download. The project has no paid Apple developer account, so there is no signed app to double-click. One script builds it for you in a minute or two.

You need macOS 26 or later on an Apple silicon Mac, Xcode 26 or later, and XcodeGen.

  1. Run this in Terminal

    LAST ONE
    git clone https://github.com/tstrider/banger-widget-mac.git
cd banger-widget-mac
./tools/install.sh

  2. Put the widget on your desktop

    LAST ONE

    Right-click an empty part of the desktop, choose Edit Widgets, find Banger, and drag the large size where you want it.

  3. Make it start when you log in

    LAST ONE

    Open System Settings, then General, then Login Items. Click + and add /Applications/Banger.app.
